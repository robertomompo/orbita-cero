Política de privacidad

Última actualización: 25 de noviembre de 2026

«Órbita Cero Publicador» es una aplicación de uso interno con la que el canal de YouTube Órbita Cero sube y programa sus propios vídeos mediante la API de datos de YouTube. Solo la utiliza el titular del canal.

Qué datos usa

  • El acceso que el titular autoriza a su propia cuenta de YouTube (lectura del canal y subida de sus vídeos).
  • Los vídeos, títulos, descripciones y miniaturas que el titular decide publicar.

Cómo se guardan

Las credenciales de acceso se guardan únicamente en el ordenador del titular, protegidas por el sistema. No se envían a ningún servidor propio ni a terceros.

Con quién se comparten

Con nadie. Los datos solo se envían a YouTube (Google) para realizar la subida. No se venden, no se usan para publicidad y no se recopilan datos de espectadores.

Servicios de terceros

Esta aplicación usa los Servicios de la API de YouTube. Al usarla se aplican los Términos del servicio de YouTube y la Política de privacidad de Google.

Cómo revocar el acceso

El acceso se puede retirar en cualquier momento desde la página de permisos de tu cuenta de Google.
